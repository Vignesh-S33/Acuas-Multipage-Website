**Acuas Multipage Website**

**Project Overview**

Acuas is a responsive multi-page website developed using HTML5 and CSS3. The project represents a modern business-style website that includes multiple sections such as Home, About, Services, Blog, Team, Products, Features, Testimonials, and Contact.

This project is designed to demonstrate front-end development skills, layout structuring, and styling techniques without using any JavaScript or backend technologies.

---

**Objectives**

* To design a clean and structured website layout
* To practice multi-page website development
* To implement CSS styling and layout techniques
* To showcase front-end development skills

---

**Key Features**

* Multi-page website structure
* Clean and modern UI design
* Navigation bar for easy page access
* Organized content sections
* Image-based layout design
* Static pages with consistent styling

---

**Pages Included**

The project contains the following pages:

* Home (`index.html`)
* About (`about.html`)
* Services (`service.html`)
* Blog (`blog.html`)
* Contact (`contact.html`)
* Our Features (`Our Features.html`)
* Our Products (`Our Products.html`)
* Our Team (`Our Team.html`)
* Testimonial (`Testimonial.html`)

---

**Technologies Used**

* HTML5 – Structure of the website
* CSS3 – Styling and layout design

**Design & Implementation Details**

### 🔹 Layout

* Each page follows a consistent layout structure
* Header with navigation menu
* Content sections (text + images)
* Footer section

### 🔹 Navigation

* Internal linking between pages
* Ensures smooth user navigation

### 🔹 Styling

* Centralized CSS file (`style.css`)
* Reusable styles across pages
* Consistent color scheme and typography

### 🔹 Images

* Images are stored in a dedicated folder
* Used for visual representation of services, team, and blog
